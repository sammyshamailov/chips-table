# שולחן צ'יפים · הוראות הקמה

האפליקציה היא קבצים סטטיים. Firebase משמש כשרת שמסנכרן את השולחן בין הטלפונים בזמן אמת, בחינם (תוכנית Spark).

## 1. פרויקט Firebase (בערך 5 דקות)
1. נכנסים ל־https://console.firebase.google.com ← **Add project** ← שם כלשהו (למשל `chips-table`). אפשר לכבות את Google Analytics.
2. בתפריט הצד: **Build ← Firestore Database ← Create database**. בוחרים מיקום (למשל `eur3`) ו־**production mode**.
3. בלשונית **Rules** של Firestore: מוחקים את מה שיש, מדביקים את התוכן של `firestore.rules` ולוחצים **Publish**.
4. בגלגל השיניים ← **Project settings ← Your apps** ← אייקון `</>` (Web). נותנים שם ולוחצים Register.
5. מעתיקים את האובייקט `firebaseConfig` שמוצג, ומדביקים את הערכים בקובץ `config.js` במקום ה־`PASTE`.

## 2. העלאה לאוויר (בחרו אחת)
- **Netlify Drop (הכי פשוט, ממחשב):** נכנסים ל־https://app.netlify.com/drop וגוררים את כל התיקייה. מקבלים קישור https מיד.
- **Firebase Hosting:** `npm i -g firebase-tools`, ואז `firebase login`, `firebase init hosting` (תיקייה `.`, לא SPA), ואז `firebase deploy`.
- **GitHub Pages:** ב־Settings ← Pages מגדירים את **Source** ל־**GitHub Actions**. אחרי מיזוג ל־`main`, האתר ייפרס אוטומטית; אפשר גם להפעיל פריסה ידנית מתוך Actions.

האתר חייב לרוץ על https כדי שההתקנה כאפליקציה תעבוד. כל האפשרויות למעלה נותנות https.

## 3. התקנה בטלפון
- **אנדרואיד (Chrome):** כפתור "התקנת האפליקציה" במסך הראשי, או תפריט ← "התקנת אפליקציה".
- **אייפון (Safari):** שיתוף ← "הוספה למסך הבית".

## 4. משחק
- מי שפותח שולחן הוא הדילר: מתחיל ידיים, מקדם רחובות, מסמן זוכים ומשלם.
- "שיתוף הזמנה" שולח קישור שפותח ישר את השולחן. אפשר גם להקליד את הקוד בן 4 האותיות.
- שחקן בלי טלפון: הדילר מוסיף אותו ממסך "שחקנים" ומנהל לו את הצ'יפים.

## הערה על אבטחה
החוקים מאפשרים לכל מי שיש לו את הקישור לקרוא ולכתוב רק לאוסף `rooms`, וזה מספיק למשחק בין חברים. לא שומרים שם שום מידע רגיש.
